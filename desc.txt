Sonic Junction Forum

Категория: Форумное веб-приложение

Стек: React, TypeScript, Supabase, HTML/CSS

Описание: Фан-платформа и тематический форум, посвященный франшизе Sonic the Hedgehog. Проект создан для объединения сообщества, публикации актуальных новостей серии и ведения дискуссий.

Функционал:

Управление темами, сообщениями и профилями пользователей.

Авторизация и надежная работа с базой данных на базе Supabase.

Адаптивный пользовательский интерфейс для комфортного чтения и навигации.

Pixel Lab

Категория: Интерактивный веб-сервис (Pixel Battle)

Стек: JavaScript / TypeScript, WebSockets, HTML5 Canvas

Описание: Онлайновая платформа для проведения массовых пиксель-батлов в реальном времени. Игроки объединяются в команды, закрашивают пиксели на общем холсте и соревнуются за территорию.

Функционал:

Синхронизация действий участников на единой карте в реальном времени.

Интеграция со стрим-трансляциями для привлечения активной аудитории.

Командная механика захвата и защиты участков холста.

LumixEngine2D

Категория: 2D-игровой движок

Стек: Rust, wgpu, LuaJIT

Описание: Низкоуровневый и производительный 2D-движок, разработанный с акцентом на скорость работы, эффективное управление ресурсами и гибкую скриптовую логику.

Функционал:

Рендеринг с использованием графического API wgpu.

Интеграция LuaJIT для написания и быстрой отладки игровой логики.

Поддержка анимации спрайт-шитов, физических AABB-столкновений и Z-index сортировки слоев.

Динамическая загрузка текстурных ресурсов.
